## 1. Descripción

Las **expresiones regulares** (*regex*) son patrones que describen conjuntos de cadenas de texto. El módulo `re` permite usarlas para:

- **Buscar** texto que cumpla un patrón (emails, teléfonos, fechas…).
- **Validar** formatos de entrada.
- **Extraer** partes concretas de un texto.
- **Reemplazar** o **dividir** texto según reglas complejas.

---

## 2. Instalación e importación

No requiere instalación.

```python
import re
```

---

## 3. Conceptos clave

| Concepto | Descripción |
|---|---|
| Patrón | La expresión regular, p. ej. `r"\d{3}"`. |
| Cadena *raw* | Prefijo `r"..."`: evita que Python interprete `\` antes que `re`. |
| Objeto `Match` | Resultado de una coincidencia: posición, texto y grupos. |
| Patrón compilado | `re.compile()`: reutilizable y más eficiente. |
| *Flags* | Modificadores: ignorar mayúsculas, multilínea, etc. |

> Use **siempre** cadenas *raw* (`r"..."`) para escribir patrones.

---

## 4. Sintaxis de expresiones regulares

### 4.1 Caracteres especiales

| Símbolo | Significado | Ejemplo | Coincide con |
|---|---|---|---|
| `.` | Cualquier carácter (salvo salto de línea) | `c.sa` | casa, cosa |
| `^` | Inicio de la cadena | `^Hola` | "Hola mundo" |
| `$` | Fin de la cadena | `fin$` | "es el fin" |
| `\` | Escapa un carácter especial | `\.` | un punto literal |
| `\|` | Alternativa (O) | `gato\|perro` | gato o perro |

### 4.2 Clases de caracteres

| Símbolo | Significado |
|---|---|
| `\d` | Dígito (0–9) |
| `\D` | No dígito |
| `\w` | Carácter de palabra (letras, dígitos, `_`; incluye tildes y ñ) |
| `\W` | No carácter de palabra |
| `\s` | Espacio en blanco (espacio, tabulador, salto de línea) |
| `\S` | No espacio |
| `\b` | Límite de palabra |
| `[abc]` | a, b o c |
| `[^abc]` | Cualquiera excepto a, b o c |
| `[a-z]` | Rango de minúsculas |
| `[A-Za-zÁÉÍÓÚáéíóúÑñ]` | Letras en español |

### 4.3 Cuantificadores

| Símbolo | Significado |
|---|---|
| `*` | 0 o más veces |
| `+` | 1 o más veces |
| `?` | 0 o 1 vez (opcional) |
| `{n}` | Exactamente n veces |
| `{n,}` | n o más veces |
| `{n,m}` | Entre n y m veces |
| `*?`, `+?`, `??` | Versiones **no codiciosas** (la menor coincidencia posible) |

### 4.4 Grupos

| Sintaxis | Significado |
|---|---|
| `(...)` | Grupo de captura |
| `(?P<nombre>...)` | Grupo con nombre |
| `(?:...)` | Grupo sin captura |
| `(?=...)` | Anticipación positiva (*lookahead*) |
| `(?!...)` | Anticipación negativa |
| `(?<=...)` | Retrospección positiva (*lookbehind*) |
| `(?<!...)` | Retrospección negativa |

## 5. Funciones del módulo

### 5.1 `re.search`: primera coincidencia en cualquier posición

```python
texto = "Pedido 4521 enviado el 24/11/2026"
m = re.search(r"\d+", texto)
if m:
    print(m.group())     # 4521
    print(m.start(), m.end(), m.span())
```

### 5.2 `re.match`: coincidencia al **inicio** de la cadena

```python
re.match(r"Pedido", texto)     # Coincide
re.match(r"\d+", texto)        # None (no empieza por dígitos)
```

### 5.3 `re.fullmatch`: la cadena **completa** debe coincidir (ideal para validar)

```python
re.fullmatch(r"\d{5}", "28001")      # Código postal válido
re.fullmatch(r"\d{5}", "28001-A")    # None
```

### 5.4 `re.findall`: todas las coincidencias como lista

```python
re.findall(r"\d+", "3 manzanas, 12 peras y 7 kiwis")   # ['3', '12', '7']
```

Si el patrón tiene grupos, devuelve los grupos:

```python
re.findall(r"(\w+)@(\w+)\.com", "ana@empresa.com, luis@correo.com")
# [('ana', 'empresa'), ('luis', 'correo')]
```

### 5.5 `re.finditer`: iterador de objetos `Match`

```python
for m in re.finditer(r"\d+", "3 manzanas, 12 peras"):
    print(m.group(), m.span())
```

### 5.6 `re.sub`: reemplazar

```python
re.sub(r"\s+", " ", "Texto   con    espacios")       # Texto con espacios
re.sub(r"\d", "*", "Tarjeta 1234 5678")              # Tarjeta **** ****
re.sub(r"(\d{2})/(\d{2})/(\d{4})", r"\3-\2-\1", "24/11/2026")   # 2026-11-24
```

Con función de reemplazo:

```python
def a_mayusculas(m):
    return m.group().upper()

re.sub(r"\b[a-z]", a_mayusculas, "hola mundo")      # Hola Mundo
```

`re.subn` devuelve además el número de reemplazos.

### 5.7 `re.split`: dividir

```python
re.split(r"[,;\s]+", "uno, dos;tres  cuatro")      # ['uno', 'dos', 'tres', 'cuatro']
```

### 5.8 `re.compile`: patrones reutilizables

```python
PATRON_EMAIL = re.compile(r"[\w.+-]+@[\w-]+\.[\w.-]+")

PATRON_EMAIL.findall(texto)
PATRON_EMAIL.search(texto)
PATRON_EMAIL.fullmatch("ana@empresa.com")
```

### 5.9 `re.escape`: buscar texto literal

```python
busqueda = "precio (IVA incl.)"
re.search(re.escape(busqueda), texto)
```

## 6. Grupos y capturas

### 6.1 Grupos numerados

```python
m = re.search(r"(\d{2})/(\d{2})/(\d{4})", "Fecha: 24/11/2026")
m.group(0)     # '24/11/2026' (coincidencia completa)
m.group(1)     # '24'
m.groups()     # ('24', '11', '2026')
```

### 6.2 Grupos con nombre (más legibles)

```python
patron = r"(?P<dia>\d{2})/(?P<mes>\d{2})/(?P<anio>\d{4})"
m = re.search(patron, "Fecha: 24/11/2026")
m.group("anio")      # '2026'
m.groupdict()        # {'dia': '24', 'mes': '11', 'anio': '2026'}
```

### 6.3 Grupos sin captura

```python
re.findall(r"(?:Sr|Sra)\.\s(\w+)", "Sr. García y Sra. López")    # ['García', 'López']
```

### 6.4 Referencias a grupos anteriores

```python
re.findall(r"\b(\w+)\s+\1\b", "es es un error de de escritura")   # ['es', 'de']
```

### 6.5 Lookahead y lookbehind

```python
# Números seguidos de "€" (sin incluir el símbolo)
re.findall(r"\d+(?=\s?€)", "Total 120 € y 45€")         # ['120', '45']

# Números precedidos de "#"
re.findall(r"(?<=#)\d+", "Tickets #101 y #205")        # ['101', '205']

# Contraseña: mínimo 8 caracteres, una mayúscula, una minúscula y un dígito
re.fullmatch(r"(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}", "Segura2026")
```

## 7. Operaciones avanzadas

### 7.1 Flags

| Flag | Abreviatura | Efecto |
|---|---|---|
| `re.IGNORECASE` | `re.I` | Ignora mayúsculas/minúsculas. |
| `re.MULTILINE` | `re.M` | `^` y `$` se aplican a cada línea. |
| `re.DOTALL` | `re.S` | `.` incluye también saltos de línea. |
| `re.VERBOSE` | `re.X` | Permite espacios y comentarios en el patrón. |
| `re.ASCII` | `re.A` | `\w`, `\d`, `\s` solo para ASCII. |

```python
re.findall(r"^error.*$", log, flags=re.I | re.M)
```

### 7.2 Patrones legibles con `re.VERBOSE`

```python
PATRON_TELEFONO = re.compile(r"""
    ^
    (?:\+34|0034)?      # Prefijo internacional opcional
    [\s-]?
    ([6789]\d{2})       # Primer bloque (móvil o fijo)
    [\s-]?
    (\d{3})
    [\s-]?
    (\d{3})
    $
""", re.VERBOSE)

PATRON_TELEFONO.fullmatch("+34 612 345 678")
```

### 7.3 Codicioso frente a no codicioso

```python
html = "<b>uno</b> y <b>dos</b>"
re.findall(r"<b>.*</b>", html)      # ['<b>uno</b> y <b>dos</b>']   (codicioso)
re.findall(r"<b>.*?</b>", html)     # ['<b>uno</b>', '<b>dos</b>']  (no codicioso)
```

### 7.4 Expresiones regulares en Pandas

```python
df["cp"] = df["direccion"].str.extract(r"(\d{5})")
df[df["email"].str.contains(r"@empresa\.com$", regex=True)]
df["telefono"] = df["telefono"].str.replace(r"\D", "", regex=True)
```

## 8. Patrones útiles

| Uso | Patrón |
|---|---|
| Email (básico) | `r"[\w.+-]+@[\w-]+\.[\w.-]+"` |
| Teléfono español | `r"(?:\+34\s?)?[6789]\d{2}\s?\d{3}\s?\d{3}"` |
| Código postal español | `r"\b(0[1-9]\|[1-4]\d\|5[0-2])\d{3}\b"` |
| DNI | `r"\b\d{8}[A-HJ-NP-TV-Z]\b"` |
| NIE | `r"\b[XYZ]\d{7}[A-HJ-NP-TV-Z]\b"` |
| Fecha dd/mm/aaaa | `r"\b(0[1-9]\|[12]\d\|3[01])/(0[1-9]\|1[0-2])/\d{4}\b"` |
| Hora hh:mm | `r"\b([01]\d\|2[0-3]):[0-5]\d\b"` |
| URL | `r"https?://[^\s/$.?#].[^\s]*"` |
| IPv4 (formato) | `r"\b(?:\d{1,3}\.){3}\d{1,3}\b"` |
| IBAN español | `r"\bES\d{2}(?:\s?\d{4}){5}\b"` |
| Importe con decimales | `r"\d{1,3}(?:\.\d{3})*,\d{2}"` |
| Hashtag | `r"#\w+"` |

> Las expresiones regulares validan el **formato**, no la validez real (por ejemplo, la letra de control del DNI debe comprobarse con un cálculo aparte).

Validación completa de DNI:

```python
LETRAS_DNI = "TRWAGMYFPDXBNJZSQVHLCKE"

def dni_valido(dni: str) -> bool:
    dni = dni.upper().replace("-", "").replace(" ", "")
    m = re.fullmatch(r"(\d{8})([A-Z])", dni)
    return bool(m) and LETRAS_DNI[int(m.group(1)) % 23] == m.group(2)
```

## 9. Ejemplo práctico completo

Analizador de un archivo de log de servidor web:

```python
import re
from collections import Counter

LOG = """\
192.168.1.10 - - [24/Nov/2026:10:15:32 +0100] "GET /index.html HTTP/1.1" 200 5320
192.168.1.22 - - [24/Nov/2026:10:16:01 +0100] "POST /api/login HTTP/1.1" 401 120
10.0.0.5 - - [24/Nov/2026:10:16:45 +0100] "GET /productos?id=45 HTTP/1.1" 200 8450
192.168.1.10 - - [24/Nov/2026:10:17:12 +0100] "GET /no-existe HTTP/1.1" 404 230
10.0.0.5 - - [24/Nov/2026:10:18:30 +0100] "POST /api/login HTTP/1.1" 500 98
"""

PATRON = re.compile(r"""
    (?P<ip>\d{1,3}(?:\.\d{1,3}){3})       # Dirección IP
    \s-\s-\s
    \[(?P<fecha>[^\]]+)\]                 # Fecha entre corchetes
    \s"
    (?P<metodo>GET|POST|PUT|DELETE|PATCH)
    \s(?P<ruta>\S+)
    \sHTTP/[\d.]+"
    \s(?P<estado>\d{3})
    \s(?P<bytes>\d+)
""", re.VERBOSE)

peticiones = [m.groupdict() for m in PATRON.finditer(LOG)]

print(f"Peticiones analizadas: {len(peticiones)}\n")

por_ip = Counter(p["ip"] for p in peticiones)
print("Peticiones por IP:")
for ip, n in por_ip.most_common():
    print(f"  {ip:<15} {n}")

errores = [p for p in peticiones if p["estado"].startswith(("4", "5"))]
print(f"\nErrores ({len(errores)}):")
for p in errores:
    print(f"  {p['estado']} {p['metodo']:<5} {p['ruta']}  ({p['ip']})")

total_kb = sum(int(p["bytes"]) for p in peticiones) / 1024
print(f"\nTráfico total: {total_kb:.1f} KB")
```

## 10. Errores frecuentes

| Problema | Causa | Solución |
|---|---|---|
| El patrón no funciona con `\d`, `\b`… | Falta el prefijo `r`. | Use cadenas *raw*: `r"\d+"`. |
| `AttributeError: 'NoneType' object has no attribute 'group'` | No hubo coincidencia. | Compruebe `if m:` antes de usar `m.group()`. |
| `match` no encuentra un texto que sí existe | `match` solo busca al inicio. | Use `search`. |
| La validación acepta textos con caracteres extra | Uso de `search` o `match`. | Use `fullmatch`. |
| Captura demasiado texto | Cuantificador codicioso. | Use `*?` o `+?`. |
| `.` no coincide con el punto literal | `.` es un comodín. | Escape: `\.`. |
| `re.error: unbalanced parenthesis` | Paréntesis literal sin escapar. | Use `\(` `\)` o `re.escape()`. |

---

## 11. Buenas prácticas

- Use siempre cadenas *raw* (`r"..."`).
- Compile los patrones que se usan repetidamente y defínalos como constantes.
- Use `fullmatch` para validar entradas completas.
- Prefiera grupos con nombre para mejorar la legibilidad.
- Use `re.VERBOSE` y comentarios en patrones complejos.
- No use regex para analizar HTML o JSON completos: use BeautifulSoup o `json`.
- Pruebe los patrones con herramientas como regex101.com (modo *Python*).
- Si una operación simple de cadenas basta (`in`, `startswith`, `split`), úsela: es más clara y rápida.

## 12. Referencia rápida

```python
re.search(p, txt)       # Primera coincidencia (o None)
re.match(p, txt)        # Coincidencia al inicio
re.fullmatch(p, txt)    # Cadena completa
re.findall(p, txt)      # Lista de coincidencias
re.finditer(p, txt)     # Iterador de Match
re.sub(p, repl, txt)    # Reemplazar
re.split(p, txt)        # Dividir
re.compile(p, flags)    # Compilar
re.escape(txt)          # Escapar texto literal
m.group() / m.group(n) / m.group("nombre") / m.groups() / m.groupdict() / m.span()
```
