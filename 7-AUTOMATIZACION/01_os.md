## 1. Descripción

El módulo `os` ofrece una interfaz portable para interactuar con el sistema operativo: gestionar archivos y carpetas, construir rutas, leer variables de entorno, consultar información del sistema y de los procesos.

**Casos de uso habituales:**
- Crear, renombrar y eliminar archivos y carpetas.
- Recorrer árboles de directorios.
- Leer configuración desde variables de entorno.
- Consultar tamaño, fechas y permisos de archivos.
- Escribir scripts que funcionen en Windows, macOS y Linux.

> Para manipular rutas, el módulo moderno **`pathlib`** suele ser más cómodo y legible. `os` sigue siendo imprescindible para variables de entorno, información del sistema, permisos y operaciones de bajo nivel.

## 3. Conceptos clave

| Concepto | Descripción |
|---|---|
| Ruta absoluta | Ruta completa desde la raíz (`C:\Datos\informe.txt`, `/home/ana/informe.txt`). |
| Ruta relativa | Ruta respecto al directorio de trabajo actual (`datos/informe.txt`). |
| Directorio de trabajo | Carpeta desde la que se resuelven las rutas relativas. |
| Separador | `\` en Windows, `/` en macOS y Linux (`os.sep`). |
| `os.path` | Submódulo para manipular rutas como texto. |
| `os.environ` | Diccionario con las variables de entorno. |

## 4. Directorio de trabajo

```python
os.getcwd()                       # Directorio actual
os.chdir("C:/Proyectos/informes") # Cambiar de directorio
os.listdir()                      # Contenido del directorio actual
os.listdir("datos")               # Contenido de otra carpeta
```

> Evite depender de `os.chdir()` en programas grandes: cambia el estado global del proceso. Prefiera trabajar con rutas absolutas.

Ruta de la carpeta donde está el script (independiente desde dónde se ejecute):

```python
CARPETA_SCRIPT = os.path.dirname(os.path.abspath(__file__))
ruta_config = os.path.join(CARPETA_SCRIPT, "config.json")
```

## 5. Rutas con os.path

### 5.1 Construir rutas portables

```python
ruta = os.path.join("datos", "2026", "ventas.csv")
# Windows: datos\2026\ventas.csv   ·   Linux/macOS: datos/2026/ventas.csv
```

> No construya rutas concatenando cadenas con `"/"` o `"\\"`: use `os.path.join` o `pathlib`.

### 5.2 Descomponer rutas

```python
ruta = "/home/ana/informes/ventas_2026.xlsx"

os.path.basename(ruta)      # 'ventas_2026.xlsx'
os.path.dirname(ruta)       # '/home/ana/informes'
os.path.split(ruta)         # ('/home/ana/informes', 'ventas_2026.xlsx')
os.path.splitext(ruta)      # ('/home/ana/informes/ventas_2026', '.xlsx')

nombre, extension = os.path.splitext(os.path.basename(ruta))
```

### 5.3 Normalizar y resolver

```python
os.path.abspath("datos/../informes")      # Ruta absoluta
os.path.normpath("datos//2026/./ventas")  # Limpia separadores y puntos
os.path.realpath("acceso_directo")        # Resuelve enlaces simbólicos
os.path.expanduser("~/Documentos")        # Expande la carpeta del usuario
os.path.expandvars("$HOME/datos")         # Expande variables de entorno
os.path.relpath("/home/ana/a/b", "/home/ana")   # 'a/b'
os.path.commonpath(["/a/b/c", "/a/b/d"])        # '/a/b'
```

### 5.4 Comprobaciones

```python
os.path.exists(ruta)        # ¿Existe (archivo o carpeta)?
os.path.isfile(ruta)        # ¿Es un archivo?
os.path.isdir(ruta)         # ¿Es una carpeta?
os.path.islink(ruta)        # ¿Es un enlace simbólico?
os.path.isabs(ruta)         # ¿Es una ruta absoluta?
os.path.samefile(a, b)      # ¿Apuntan al mismo archivo?
```

## 6. Archivos y directorios

### 6.1 Crear carpetas

```python
os.mkdir("salida")                              # Una carpeta (error si existe o falta la carpeta padre)
os.makedirs("salida/2026/noviembre", exist_ok=True)   # Crea toda la estructura
```

### 6.2 Renombrar y mover

```python
os.rename("informe.txt", "informe_final.txt")
os.rename("informe.txt", "archivo/informe.txt")      # Mover (mismo disco)
os.replace("nuevo.txt", "actual.txt")                # Reemplaza el destino si existe
os.renames("a/b/viejo.txt", "c/d/nuevo.txt")         # Crea carpetas intermedias
```

> Para mover entre discos distintos use `shutil.move()`.

### 6.3 Eliminar

```python
os.remove("temporal.txt")               # Eliminar archivo
os.unlink("temporal.txt")               # Equivalente
os.rmdir("carpeta_vacia")               # Eliminar carpeta vacía
os.removedirs("a/b/c")                  # Elimina c, b y a si quedan vacías
```

> Para eliminar una carpeta con contenido use `shutil.rmtree()`. Las eliminaciones con `os` son **definitivas** (no pasan por la papelera).

### 6.4 Listar contenido

```python
os.listdir("datos")                      # Lista de nombres

# os.scandir: más eficiente y con información de cada entrada
with os.scandir("datos") as entradas:
    for e in entradas:
        tipo = "DIR " if e.is_dir() else "FILE"
        print(tipo, e.name, e.stat().st_size if e.is_file() else "")
```

Filtrar por extensión:

```python
csvs = [f for f in os.listdir("datos") if f.lower().endswith(".csv")]
```

### 6.5 Permisos

```python
os.access(ruta, os.R_OK)        # ¿Se puede leer?
os.access(ruta, os.W_OK)        # ¿Se puede escribir?
os.access(ruta, os.X_OK)        # ¿Se puede ejecutar?

os.chmod("script.sh", 0o755)    # rwxr-xr-x (Linux/macOS)
os.chmod(".env", 0o600)         # Solo el propietario puede leer y escribir
```

### 6.6 Enlaces

```python
os.symlink("origen.txt", "enlace.txt")      # Enlace simbólico (en Windows requiere permisos)
os.link("origen.txt", "enlace_duro.txt")    # Enlace duro
os.readlink("enlace.txt")
```

## 7. Recorrer árboles de carpetas

### 7.1 `os.walk`

Recorre recursivamente una carpeta y todas sus subcarpetas:

```python
for carpeta, subcarpetas, archivos in os.walk("proyecto"):
    print(f"📁 {carpeta}")
    for nombre in archivos:
        print(f"    📄 {nombre}")
```

### 7.2 Buscar archivos por extensión

```python
def buscar(raiz: str, extensiones: tuple[str, ...]) -> list[str]:
    encontrados = []
    for carpeta, _, archivos in os.walk(raiz):
        for nombre in archivos:
            if nombre.lower().endswith(extensiones):
                encontrados.append(os.path.join(carpeta, nombre))
    return encontrados

buscar("C:/Documentos", (".pdf", ".docx"))
```

### 7.3 Excluir carpetas durante el recorrido

```python
EXCLUIR = {".git", "__pycache__", "node_modules", ".venv"}

for carpeta, subcarpetas, archivos in os.walk("proyecto"):
    subcarpetas[:] = [d for d in subcarpetas if d not in EXCLUIR]   # Modificar en el sitio
    ...
```

### 7.4 Calcular el tamaño de una carpeta

```python
def tamano_carpeta(raiz: str) -> int:
    total = 0
    for carpeta, _, archivos in os.walk(raiz):
        for nombre in archivos:
            ruta = os.path.join(carpeta, nombre)
            if not os.path.islink(ruta):
                total += os.path.getsize(ruta)
    return total

print(f"{tamano_carpeta('datos') / 1024**2:.1f} MB")
```

### 7.5 Recorrido de abajo arriba

```python
# Útil para eliminar carpetas vacías (primero las más profundas)
for carpeta, subcarpetas, archivos in os.walk("salida", topdown=False):
    if not os.listdir(carpeta):
        os.rmdir(carpeta)
```

## 8. Información de archivos

### 8.1 Tamaño y fechas

```python
os.path.getsize("informe.pdf")       # Bytes
os.path.getmtime("informe.pdf")      # Última modificación (timestamp)
os.path.getctime("informe.pdf")      # Creación (Windows) / cambio de metadatos (Unix)
os.path.getatime("informe.pdf")      # Último acceso
```

Convertir a fecha legible:

```python
from datetime import datetime

marca = os.path.getmtime("informe.pdf")
print(datetime.fromtimestamp(marca).strftime("%d/%m/%Y %H:%M"))
```

### 8.2 `os.stat` (información completa)

```python
info = os.stat("informe.pdf")
info.st_size          # Tamaño en bytes
info.st_mtime         # Modificación
info.st_mode          # Tipo y permisos
info.st_uid           # Propietario (Unix)
```

### 8.3 Formatear tamaños

```python
def tamano_legible(bytes_: int) -> str:
    for unidad in ("B", "KB", "MB", "GB", "TB"):
        if bytes_ < 1024:
            return f"{bytes_:.1f} {unidad}"
        bytes_ /= 1024
    return f"{bytes_:.1f} PB"
```

### 8.4 Cambiar fechas de un archivo

```python
import time
ahora = time.time()
os.utime("informe.pdf", (ahora, ahora))       # (acceso, modificación)
```

## 9. Variables de entorno

```python
os.environ                              # Diccionario con todas las variables
os.environ["PATH"]                      # Lectura (KeyError si no existe)
os.getenv("API_TOKEN")                  # None si no existe
os.getenv("APP_PUERTO", "8000")         # Valor por defecto
os.environ["APP_MODO"] = "pruebas"      # Definir (solo para este proceso y sus hijos)
del os.environ["APP_MODO"]              # Eliminar
os.environ.get("HOME") or os.environ.get("USERPROFILE")   # Carpeta del usuario
```

Variables útiles:

| Variable | Contenido |
|---|---|
| `PATH` | Rutas donde se buscan ejecutables. |
| `HOME` (Unix) / `USERPROFILE` (Windows) | Carpeta del usuario. |
| `USERNAME` (Windows) / `USER` (Unix) | Usuario actual. |
| `TEMP` / `TMP` / `TMPDIR` | Carpeta temporal. |
| `APPDATA`, `LOCALAPPDATA` | Datos de aplicaciones (Windows). |
| `COMPUTERNAME` | Nombre del equipo (Windows). |

Recorrer la variable `PATH`:

```python
for ruta in os.environ["PATH"].split(os.pathsep):
    print(ruta)
```

> Para cargar variables desde un archivo `.env`, use **python-dotenv**.

## 10. Procesos y sistema

### 10.1 Información del sistema

```python
os.name               # 'nt' (Windows) o 'posix' (Linux/macOS)
os.sep                # Separador de rutas: '\\' o '/'
os.pathsep            # Separador de PATH: ';' o ':'
os.linesep            # Fin de línea: '\r\n' o '\n'
os.cpu_count()        # Número de núcleos
os.getlogin()         # Usuario que inició sesión
os.getpid()           # ID del proceso actual
os.getppid()          # ID del proceso padre
os.devnull            # Ruta del "agujero negro" ('nul' o '/dev/null')
```

Para más detalle, combine con el módulo `platform`:

```python
import platform
platform.system()       # 'Windows', 'Linux', 'Darwin'
platform.release()
platform.node()         # Nombre del equipo
platform.python_version()
```

### 10.2 Código específico por sistema

```python
if os.name == "nt":
    carpeta_datos = os.path.join(os.environ["APPDATA"], "MiApp")
else:
    carpeta_datos = os.path.expanduser("~/.miapp")
os.makedirs(carpeta_datos, exist_ok=True)
```

### 10.3 Abrir un archivo con la aplicación predeterminada

```python
import subprocess, sys

def abrir(ruta: str) -> None:
    if os.name == "nt":
        os.startfile(ruta)                          # Solo Windows
    elif sys.platform == "darwin":
        subprocess.run(["open", ruta], check=False)
    else:
        subprocess.run(["xdg-open", ruta], check=False)
```

### 10.4 Ejecutar comandos

```python
os.system("dir")         # Ejecuta un comando y devuelve el código de salida (no captura la salida)
```

> Para ejecutar programas, **use `subprocess`**: es más seguro y permite capturar la salida y gestionar errores.

### 10.5 Espacio en disco

```python
import shutil
total, usado, libre = shutil.disk_usage("C:/" if os.name == "nt" else "/")
print(f"Libre: {libre / 1024**3:.1f} GB")
```

## 11. Ejemplo práctico completo

Organizador de la carpeta de descargas: clasifica los archivos por tipo en subcarpetas, evita sobrescribir, ignora archivos en uso y genera un informe.

```python
import os
from datetime import datetime

CATEGORIAS = {
    "Documentos": {".pdf", ".doc", ".docx", ".txt", ".odt", ".rtf"},
    "Hojas de cálculo": {".xls", ".xlsx", ".csv", ".ods"},
    "Presentaciones": {".ppt", ".pptx", ".odp"},
    "Imágenes": {".jpg", ".jpeg", ".png", ".gif", ".bmp", ".webp", ".svg", ".heic"},
    "Vídeos": {".mp4", ".mov", ".avi", ".mkv", ".wmv"},
    "Audio": {".mp3", ".wav", ".flac", ".m4a", ".ogg"},
    "Comprimidos": {".zip", ".rar", ".7z", ".tar", ".gz"},
    "Instaladores": {".exe", ".msi", ".dmg", ".pkg", ".deb"},
    "Código": {".py", ".js", ".html", ".css", ".json", ".sql", ".ipynb"},
}
TEMPORALES = {".crdownload", ".part", ".tmp", ".download"}


def categoria_de(nombre: str) -> str:
    extension = os.path.splitext(nombre)[1].lower()
    for categoria, extensiones in CATEGORIAS.items():
        if extension in extensiones:
            return categoria
    return "Otros"


def ruta_sin_conflicto(destino: str) -> str:
    """Si el archivo existe, añade (1), (2)… al nombre."""
    if not os.path.exists(destino):
        return destino
    base, ext = os.path.splitext(destino)
    n = 1
    while os.path.exists(f"{base} ({n}){ext}"):
        n += 1
    return f"{base} ({n}){ext}"


def organizar(carpeta: str, simulacion: bool = True) -> dict[str, list[str]]:
    carpeta = os.path.abspath(os.path.expanduser(carpeta))
    if not os.path.isdir(carpeta):
        raise NotADirectoryError(carpeta)

    movimientos: dict[str, list[str]] = {}
    with os.scandir(carpeta) as entradas:
        for entrada in entradas:
            if not entrada.is_file() or entrada.name.startswith("."):
                continue
            if os.path.splitext(entrada.name)[1].lower() in TEMPORALES:
                continue                                   # Descarga en curso

            categoria = categoria_de(entrada.name)
            carpeta_destino = os.path.join(carpeta, categoria)
            destino = ruta_sin_conflicto(os.path.join(carpeta_destino, entrada.name))

            if not simulacion:
                os.makedirs(carpeta_destino, exist_ok=True)
                try:
                    os.rename(entrada.path, destino)
                except PermissionError:
                    print(f"⚠ En uso, se omite: {entrada.name}")
                    continue
            movimientos.setdefault(categoria, []).append(os.path.basename(destino))
    return movimientos


def informe(movimientos: dict[str, list[str]], simulacion: bool) -> None:
    modo = "SIMULACIÓN (no se ha movido nada)" if simulacion else "EJECUCIÓN"
    print(f"\n=== Organizador de archivos · {modo} · {datetime.now():%d/%m/%Y %H:%M} ===")
    total = 0
    for categoria in sorted(movimientos):
        archivos = movimientos[categoria]
        total += len(archivos)
        print(f"\n📁 {categoria} ({len(archivos)})")
        for nombre in sorted(archivos)[:10]:
            print(f"   • {nombre}")
        if len(archivos) > 10:
            print(f"   … y {len(archivos) - 10} más")
    print(f"\nTotal: {total} archivos")


if __name__ == "__main__":
    descargas = os.path.join(os.path.expanduser("~"), "Downloads")
    resultado = organizar(descargas, simulacion=True)       # Revise primero el resultado
    informe(resultado, simulacion=True)
    # organizar(descargas, simulacion=False)               # Ejecución real
```

## 12. Errores frecuentes

| Error | Causa | Solución |
|---|---|---|
| `FileNotFoundError` | Ruta incorrecta o relativa a otro directorio. | Use rutas absolutas basadas en `__file__`. |
| `FileExistsError` en `mkdir` | La carpeta ya existe. | Use `os.makedirs(ruta, exist_ok=True)`. |
| `PermissionError` | Archivo abierto por otro programa o sin permisos. | Cierre el archivo o ejecute con permisos adecuados. |
| `OSError: [WinError 145] Directory not empty` | `os.rmdir` sobre carpeta con contenido. | Use `shutil.rmtree`. |
| `OSError: [WinError 17]` al renombrar | Origen y destino en discos distintos. | Use `shutil.move`. |
| Rutas con `\` que fallan (`"C:\nuevo"`) | `\n` se interpreta como salto de línea. | Use `r"C:\nuevo"`, `"C:/nuevo"` o `os.path.join`. |
| `KeyError` en `os.environ[...]` | La variable no existe. | Use `os.getenv(nombre, defecto)`. |
| `AttributeError: module 'os' has no attribute 'startfile'` | `startfile` solo existe en Windows. | Use `open`/`xdg-open` en otros sistemas. |

## 13. Buenas prácticas

- Use `os.path.join` o `pathlib` para construir rutas; nunca concatene separadores a mano.
- Calcule las rutas a partir de `__file__` para que el script funcione desde cualquier carpeta.
- Use `exist_ok=True` al crear carpetas.
- Prefiera `os.scandir` a `os.listdir` cuando necesite información de cada entrada.
- Incluya un **modo simulación** en scripts que mueven o eliminan archivos.
- Capture `PermissionError` y `FileNotFoundError` en operaciones sobre archivos.
- Use `subprocess` en lugar de `os.system`.
- Para código nuevo centrado en rutas, considere `pathlib`.
